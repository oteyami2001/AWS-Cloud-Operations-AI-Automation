# Security controls

## AI safety: recommend, never execute

| Control | Where | Verified by |
|---|---|---|
| Analyzer role has **no** SSM / ECS write / PassRole permissions | `terraform/modules/aiops/iam.tf` | `terraform test` → `analyzer_cannot_change_infrastructure` |
| Only the approval function may call `ssm:StartAutomationExecution`, scoped to the 4 approved documents | `iam.tf` (`StartApprovedRunbooksOnly`) | `terraform test` → `only_remediation_function_starts_automation` |
| Model output is a JSON schema whose `recommended_runbook` is an **enum** of approved ids for the incident category, re-validated in code | `src/aiops/ai.py` | `tests/unit/test_ai.py` |
| Evidence is passed as untrusted data; prompt-injection attempt cannot escape the catalog | `ai.py` system prompt + validation | `test_prompt_injection_in_evidence_cannot_escape_catalog` |
| Secrets/tokens redacted from evidence before storage or Bedrock | `src/aiops/evidence.py` `redact()` | `test_redact`, `test_collect_all_sources` |
| Runbook parameters built from the incident's trusted resource ids, never from model output or request body | `src/aiops/runbooks.py` | `test_catalog_parameters_come_from_trusted_resource` |
| Bedrock failure / refusal / malformed output → deterministic rules engine | `ai.py` | `test_refusal_falls_back`, `test_api_error_falls_back`, `test_malformed_json_falls_back` |
| Severity is deterministic, not model-decided | `src/aiops/severity.py` | `test_severity_base_and_escalation` |

## Human approval

| Control | Detail |
|---|---|
| IAM-authenticated endpoint | Lambda Function URL `authorization_type = AWS_IAM` (asserted by `terraform test`). No anonymous access. |
| Verified approver identity | Taken from `requestContext.authorizer.iam.userArn`; a spoofed `approver` field in the body is ignored (`test_body_cannot_spoof_approver`). |
| Approver allowlist | Caller ARN must start with the operator role's assumed-role prefix (`test_non_operator_refused`). |
| MFA | Operator and senior-approver roles require `aws:MultiFactorAuthPresent` by default (`require_mfa`). |
| Justification + audit trail | ≥10-char justification required; every action appended to incident history with actor and time; SSM executions tagged with `IncidentId` / `ApprovedBy`; CloudTrail records all API calls. |
| Idempotency | Second approval on a remediating incident → 409 (`test_double_approval_conflict`). |
| Two-person rule (HIGH risk) | `RollbackEcsTaskDefinition` starts with `aws:approve`; only the **senior-approver** role (`ssm:SendAutomationSignal`) can approve; the operator role has no such permission (`access.tf`). The `aws:approve` first step is asserted by `test_every_catalog_runbook_has_a_matching_ssm_document`. |

## Least privilege (IAM)

- One role per Lambda; resource-scoped to the incident table, alerts topic, the single ECS service,
  the app log group, and this environment's alarms. `"*"` appears only for APIs that do not
  support resource-level permissions (`GetMetricData`, `DescribeTargetHealth`, X-Ray, ECR auth),
  each commented inline.
- SSM automation role: `ecs:UpdateService` on **one** service ARN; trust limited by
  `aws:SourceAccount` + `aws:SourceArn`.
- ECS task role has no permissions; execution role reads only its own secret and ECR repo.
- CI: GitHub OIDC (no stored AWS keys) with exact-match trust (`StringEquals` on `sub`/`aud`):
  - The plan role (describe-only, no data reads) trusts `main` and pull requests.
  - The image-push role (one ECR repository) trusts `main`.
  - The apply role trusts only the reviewer-gated `aws-dev` environment. It is limited to the
    services in use in `us-east-2`, and may create IAM roles only when the
    `aiops-dev-workload-boundary` permissions boundary is attached.
  - Explicit denies cover boundary removal, IAM users/keys, Organizations, CloudTrail tampering and
    the CI roles themselves.
  - Full review: [`security-review.md`](security-review.md).

## Encryption & secrets

- One customer-managed KMS key (rotation on) for: CloudWatch Logs, DynamoDB, SNS, SQS, ECR, Lambda
  environment variables, Secrets Manager.
- The fault-injection token is generated by Secrets Manager as an **ephemeral** value and written with
  a **write-only** argument (`secret_string_wo`), so it is never stored in Terraform state or plan
  files. ECS injects it as a container secret, and the app compares it in constant time.
- Terraform state: S3 (SSE-S3, versioned, TLS-only, Block Public Access, ACLs off) with S3-native
  locking. `*.tfstate` and `backend.tf` are git-ignored.
- No secrets in code, tfvars, or workflow files.

## Network

- ALB ingress restricted to `allowed_ingress_cidrs` (required variable, validated non-empty).
- Task security group accepts traffic only from the ALB SG; egress only 443.
- Default security group locked down; ALB drops invalid headers.

## Supply chain / CI

- Ruff (incl. flake8-bandit rules), Bandit SAST, pytest with 85% coverage gate.
- Checkov on all Terraform (fails on any un-justified finding), tflint (AWS ruleset), Trivy config scan.
- All GitHub Actions pinned to full commit SHAs; `persist-credentials: false`.
- Container image built, smoke-tested read-only, and scanned with Trivy (HIGH/CRITICAL).
- Pinned dependency versions; deterministic Lambda zip.

## Accepted risks (demo scope) - each skipped inline with `checkov:skip` + reason

| Finding | Reason | Production fix |
|---|---|---|
| HTTP listener, no TLS (CKV_AWS_2/103/378, CKV2_AWS_20) | No domain/ACM cert in a personal account; ingress limited to owner IP | ACM certificate + HTTPS listener + redirect |
| No WAF (CKV2_AWS_28) | Cost/scope | AWS WAF managed rules on the ALB |
| Public subnets, public task IP (CKV_AWS_130/333) | No NAT (cost) | Private subnets + VPC endpoints / NAT |
| No ALB access logs, Container Insights, flow logs by default | Cost | Enable variables |
| Lambda not in VPC, no code signing (CKV_AWS_117/272) | Calls only public AWS APIs | VPC + endpoints; AWS Signer |
| 14-day log retention (CKV_AWS_338) | Cost | ≥ 1 year per policy |
| No deletion protection on ALB / DynamoDB | Must be destroyable | Enable |
